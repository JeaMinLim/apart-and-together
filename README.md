# 따로또같이 (Apart & Together)

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![Status](https://img.shields.io/badge/status-brainstorming-lightgrey.svg)](#현재-상태)

**따로또같이**는 여러 사람이 각자 자신의 AI를 이용해 하나의 목표를 함께 만들어가는 협업 방법을 찾는 프로젝트입니다.

각자는 **따로** 작업하지만 결국 **같이** 하나의 결과물로 완성된다는 아이디어에서 이름을 지었습니다.
