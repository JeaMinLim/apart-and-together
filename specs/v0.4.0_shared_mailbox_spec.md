# 따로또같이 공유 우편함 (Shared Mailbox) 구현 명세서

> 이 문서는 유료 API 키 없이, 각 구독형 AI(Claude Desktop, Cursor, ChatGPT 등)가 로컬 MCP 서버를 매개로 일감과 코드 리뷰를 교환할 수 있는 "공유 우편함(Blackboard/Mailbox)"의 구현 명세서입니다.

## 0. 배경 및 목적

- 사용자는 여러 개의 AI를 유료 구독(ChatGPT Plus, Claude Pro, Cursor Pro 등)하고 있으나, 개발자 API 키는 보유하고 있지 않거나 추가 과금을 원치 않음.
- MCP 클라이언트끼리는 P2P 직접 통신이 불가능하지만, **로컬 MCP 서버(`apart-and-together`)를 중앙 공유 우편함(Mailbox)으로 활용**하면 각 구독 앱이 일감을 올리고 서로의 결과를 읽어갈 수 있음.
- 이를 통해 **추가 API 비용 0원**으로 구독형 AI 간의 실질적인 협업(코드 작성 → 교차 리뷰 → 피드백 반영)을 달성한다.

## 1. 만들 것

### 1.1. 로컬 우편함 스토리지 (`src/mailbox/store.py`)

- 로컬 파일(`.mailbox/tasks.json`) 기반의 경량 JSON 저장소
- 동시 접근 시 안전한 원자적 파일 쓰기(atomic write)
- 데이터 모델:
  - `task_id`: 고유 식별자 (예: `task-20260909-01`)
  - `title`: 작업 제목
  - `task_type`: `code_review`, `code_generation`, `question` 등
  - `content`: 코드나 질문 내용
  - `author`: 등록한 AI/사용자 (예: `claude-desktop`)
  - `created_at`: 생성 일시
  - `status`: `pending` (대기 중), `in_progress` (진행 중), `completed` (완료)
  - `results`: 다른 AI들이 제출한 결과 목록 (기여자 이름, 제출 일시, 결과 본문, AST 보안 검사 결과)

### 1.2. MCP 우편함 도구들 (`src/mcp_server.py`)

Claude Desktop, Cursor 등 모든 MCP 클라이언트에 노출될 5가지 도구:

1. `post_task_to_mailbox`: 새 일감(코드 리뷰, 기능 구현 등)을 우편함에 등록
2. `get_pending_tasks`: 아직 처리되지 않았거나 리뷰를 기다리는 일감 목록 조회
3. `get_task_details`: 특정 일감의 전체 내용 및 지금까지 제출된 피드백 확인
4. `submit_task_result`: 다른 AI가 코드 리뷰나 작업 결과를 우편함에 제출 (제출된 코드에 대해 Phase 1 AST 보안 검사 자동 실행)
5. `get_completed_task_results`: 원 작성자 AI가 다른 AI들의 피드백을 한꺼번에 조회하여 최종 반영

### 1.3. 터미널 CLI 우편함 관리 (`./bin/multi-ai mailbox`)

사용자가 터미널에서도 우편함 현황을 확인하고 관리할 수 있는 CLI 하위 명령어:
- `multi-ai mailbox list`: 현재 우편함의 모든 일감 상태 출력
- `multi-ai mailbox view <task_id>`: 일감 상세 및 AI들의 피드백 출력
- `multi-ai mailbox clear`: 우편함 비우기

### 1.4. 단위 테스트 (`tests/test_mailbox.py`)

- 일감 등록, 조회, 결과 제출, 상태 전이 테스트
- 결과 제출 시 파이썬 코드 포함 시 Phase 1 AST 보안 감사 연동 테스트
- 파일 격리 및 동시성 안전성 테스트

## 2. 검증 포인트

- `tests/test_mailbox.py` 전수 통과
- Claude Desktop과 Cursor 양쪽에서 동일한 `task_id`를 조회하고 응답을 주고받을 수 있는지 검증
- Phase 1 AST 보안 감사가 악성 코드가 포함된 리뷰/결과물을 정확히 감지하는지 확인
