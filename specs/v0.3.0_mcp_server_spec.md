# 따로또같이 MCP 서버 구현 명세서

> 이 문서는 구독형 AI(Claude Desktop, Cursor 등)를 연결하여 API 키 없이도 다중 AI 생태계에 참여할 수 있도록 하는 표준 MCP(Model Context Protocol) 서버의 작업 지시서입니다.

## 0. 배경 및 목적

- 사용자가 결제 중인 구독형 AI(Claude Pro, Cursor Pro 등)는 별도의 API 키를 제공하지 않음.
- 대신 이들 클라이언트는 **MCP(Model Context Protocol)**를 네이티브로 지원함.
- 따라서 `apart-and-together`가 로컬 MCP 서버(stdio 기반 JSON-RPC 2.0)로 동작하여, 구독형 AI가 Multi-AI Hub 및 Phase 1 AST 보안 검사기를 도구(Tools)로 직접 활용할 수 있도록 지원한다.

## 1. 만들 것

### 1.1. 로컬 MCP 서버 (`src/mcp_server.py`)

- **프로토콜**: JSON-RPC 2.0 over Standard I/O (stdin/stdout)
- **외부 의존성 제로**: 파이썬 표준 라이브러리(`sys`, `json`, `io`) 기반으로 즉각적인 시작 속도와 완벽한 호환성 보장
- **지원 메서드**:
  - `initialize`: 서버 메타데이터 및 도구(Tools) 지원 역량 선언
  - `notifications/initialized`: 클라이언트 연결 확인
  - `ping`: 헬스체크
  - `tools/list`: 노출 도구 목록 및 JSON Schema 반환
  - `tools/call`: 개별 도구 실행 및 결과 반환

### 1.2. 노출할 MCP 도구 목록

1. `get_multi_ai_status`
   - 현재 허브에 활성화된 AI 모델 목록 및 상태 반환
2. `ask_other_ais`
   - 프롬프트와 대상 모델(선택)을 입력받아 다른 AI(ChatGPT, Gemini, Grok 등)에게 동시 질의 후 결과 반환
   - 이를 통해 구독 AI(예: Claude Desktop)가 본인의 추론 외에 다른 AI들의 의견을 함께 교차 검토 가능
3. `synthesize_with_other_ais`
   - 여러 AI의 의견을 취합하여 하나의 종합 답변을 요청
4. `audit_code_security`
   - Python 코드를 인자로 받아 Phase 1의 AST 보안 스캐너(`src/verify/ast_scanner.py`)를 실행
   - `eval`, `exec`, `os.system`, `subprocess` 등 위험 호출 탐지 결과 및 보안 권고안 반환

### 1.3. 클라이언트 연동 가이드 문서

- `docs/MCP_SETUP.md`: Claude Desktop (`claude_desktop_config.json`) 및 Cursor MCP 설정 방법 안내

### 1.4. 단위 테스트 (`tests/test_mcp_server.py`)

- `initialize`, `tools/list`, `tools/call` JSON-RPC 통신 모의 테스트
- 도구 실행 결과 정상 포맷 반환 검증

## 2. 검증 포인트

- `python3 -m unittest tests/test_mcp_server.py` 전수 통과
- `python3 src/verify/ast_scanner.py src tests` 실행 시 보안 위반 0건 유지
